- 2026-07-29: The live seed survives a restart. It only ever existed as `self._seed` in memory and `on_start` unconditionally queued the default host, so every reboot or redeploy silently dropped the show back to default Bob — hit eight times in one session of development restarts. `SeedState.to_storage()/from_storage()` round-trip the resolved seed (not the original request: re-running the interpreter at boot would add an LLM call to startup and could legitimately resolve differently, changing the show on every restart). Stored per instance in the `config` table via `ConfigStore`, which meant adding `config_store` to `PluginContext` — the contract test from 2026-07-27 covers that it stays in sync with `ctx_kwargs`. - 2026-07-29: Per-track music loudness normalisation (see `doc/2026-07-27 health-checkup.md`). Library source loudness spans -34.7 to +10.0 LUFS; a master `music_vol` trim moved the average and left the 44.7 dB spread. `bridge/audio/loudness.py` measures integrated loudness and true peak once per file, gain rides to Liquidsoap as `annotate:replay_gain` applied by `amplify(override=)`, boost bounded by the track's own peak headroom. Two bugs caught in testing: the `dB` suffix is mandatory (Liquidsoap reads a bare float as a *linear* factor, so `"-5.00"` meant 5x with inverted phase — clipping audio went out until it was caught), and "pending" must mean "never attempted" or every batch re-fetches the same broken files. A/B measured with the bridge stopped: 16.1 dB apart and clipping before, 0.8 dB apart after.

- 2026-07-28: Fixed bug 5 — booth log rotates daily and its files carry dates. Was a plain `FileHandler` appending since 2026-03-31: 46.8 MB, 471 776 lines, 119 days, no cap, no `logrotate.d`.
