# RadioDan Journal

- 2026-07-28: Fixed bug 5 — booth log rotates daily and its files carry dates. Was a plain `FileHandler` appending since 2026-03-31: 46.8 MB, 471 776 lines, 119 days, no cap, no `logrotate.d`. Growth was never the issue — `QUEUE` was 299k of those lines and ~261k came from the May 2–8 freeze alone; measured steady state is ~0.10 MB/day (~3 MB/month). The real defect was `BoothFormatter` stamping `%H:%M:%S` only, so no line could be dated — which is why this checkup had to reconstruct the June outage from `event_log` and journald instead. Now `TimedRotatingFileHandler(when="midnight", backupCount=30, encoding="utf-8", utc=False)`: date lives in the filename (`booth.log.YYYY-MM-DD`) so lines stay scannable, local midnight matches the formatter's local stamps, and explicit UTF-8 guards against a minimal systemd locale mangling the emoji. Note `retention_days=0` means keep everything (stdlib skips pruning at `backupCount=0`); negatives clamp there rather than discarding history. Moved the legacy file to `logs/booth-archive-2026-03-31_to_2026-07-28.log` first — left alone it would have been renamed `booth.log.2026-07-28` at midnight, labelling 119 days as one; the archive name doesn't match the handler's date pattern so pruning ignores it. Left `QUEUE` verbosity alone: at ~1440 lines/day the detail is worth more, and the one time it exploded that noise was the signal. 15 tests, suite 142 passed.

- 2026-07-28: Fixed bug 1 from the checkup — the seed's `hard` flag is a one-shot again. It was re-read on every script build, so one `{"hard":true}` seed cut a track mid-song every ~50 min rebuild for as long as it stayed live (23 days in the case found). Fixed structurally: `_build_script` takes keyword-only `apply_hard=False` and the skip moved to `_maybe_hard_skip()`; of the four call sites (seed, `buffer_low`, skip reaction, mood) only the seed handler passes it, as `not silent_default`. `SeedState.hard_consumed` is the second guard, surfaced in `/api/producer/status` alongside the requested `hard`, and marked before the skip is attempted so a half-failed skip can't lie in wait. Verified live: a hard hip-hop seed cut Ulf Lundell into Cypress Hill (one skip), then three `/api/producer/mood` rebuilds produced zero further skips. 10 tests including a 660-cycle simulation; reverting the fix makes it `assert 661 == 1`.
